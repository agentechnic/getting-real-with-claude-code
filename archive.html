Getting Real with Claude Code

The earlier version of this workshop, run in Riyadh through 2026. Everyone built receipts, a Python CLI that pulls structured data out of receipt files into a SQLite ledger and emits deterministic CSV reports.

It is kept here because it still works and because people who attended it still use it. The current workshop teaches a different move: doing the work once, then turning it into something that repeats.
